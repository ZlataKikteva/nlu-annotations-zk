# Sentence interpretation task

### Task overview

You will see a sentence from WikiHow, with short context before and after it. Then you will see a question about some aspect of this sentence and several answer options. 

Select every answer option that you believe can be inferred from the instruction sentence. Ask yourself: Could have the writer meant this when they wrote the instruction?

You can select one or several options. If none of the options is communicated by the sentence, select "None can be inferred from the target sentence".

There are no right or wrong answers. To proceed to the study, select "Qualification" in the sidebar on the left.
